# 真实媒体样本回归记录

## 指标定义

本记录使用一组已获授权、未提交到仓库的 5 分 33 秒中文动画成片与对应剧本。剧本解析后得到 99 句有效台词。

`候选失误率 = (疑似改词 + 疑似漏词) / 剧本有效台词数`。

“未匹配语音”仅作为低优先级回听提示，不直接计为剧本错误。“待听确认”表示字幕与剧本一致、但 ASR 没有稳定语音证据；它既不冒充正确，也不直接计为漏词。

## 回归结果

| 阶段 | 自动通过 | 待听确认 | 疑似改词 | 疑似漏词 | 候选失误率 |
|---|---:|---:|---:|---:|---:|
| 原始基线 | 39 | 0 | 29 | 31 | 60.61% |
| 全时轴 OCR 后 | 91 | 0 | 0 | 8 | 8.08% |
| 早期证据门控缓存 | 99 | 0 | 0 | 0 | 0.00% |
| 当前多候选 ASR + 待听确认 + 人工工作台 | 90 | 9 | 0 | 0 | 0.00% |

当前完整重跑产生 110 个 ASR 时间片段、135 条去重字幕观察，并保留 2 段低优先级未匹配语音供人工回听。9 条待听确认可在人工工作台中回听、补写时间码转写并映射角色；应用后无需重复执行模型。

## 轻量说话人阶段 B 回归

- 指定 3 个主要说话人时，110 个 ASR 片段被分为 3 个声学组，平均分组置信度约 64%–71%。
- 三组的剧本角色多数置信度分别约为 45%、56%、66%，均未达到 78% 自动角色门槛，因此自动写入角色为 0。
- 收紧冲突门槛后，角色冲突候选为 0；没有把这份声音区分度不足的动画素材制造成 20 条假问题。
- `0 = 自动估计` 模式得到 2 个声音组，角色多数置信度约为 54% 和 64%，同样安全降级为人工确认。
- 声学组表示音色/频谱相似片段，不是身份级声纹；该样本没有说话人金标，因此不报告“说话人准确率”。

## 重要局限

- 0.00% 是该单一授权样本的候选失误率，不是行业泛化准确率。
- 样本本身需由编导确认剧本与成片一致；未有独立标注员的外部金标。
- 当前“轻量语义一致”只做受数字、否定词和方向/动作反义词保护的归一，不等价于大模型语义理解。
- 下一阶段必须用多组真实成片/剧本对做盲测，分别报告误报、漏报和人工复核率。

## 可重复工具

`python -m eval.run_multimodal_sample <video> <script> --model base --ocr --speaker-count 0` 可在本地对已授权媒体对运行完整回归，并可用 `--output` 保存本地 JSON。输入媒体、输出缓存和本地路径都不应提交到公开仓库。
