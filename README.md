# ScriptLint

一个以“反馈记忆”为核心的短剧成片音频 + 字幕审片 Agent Demo。

用户可以上传自己的短剧成片和对照剧本。系统提取音轨生成中文 ASR，同时抽取画面硬字幕，与剧本进行三方比对；编导提交纠正后，系统把自然语言意见转成待确认规则，只有人工确认的规则才会在同一项目的后续版本中复用。

## 当前能力

- 上传 `.mp4`、`.mov`、`.mkv`、`.webm`、`.avi`、`.m4v` 视频；
- 使用 PyAV 从视频容器提取 16kHz 单声道 WAV，无需系统单独安装 FFmpeg；
- 使用 faster-whisper CPU INT8 生成中文时间码转写；
- 使用 RapidOCR 按 ASR 时间点抽取下半屏硬字幕，辅助判断中文同音字；
- 当字幕与剧本一致、ASR 仅为部分匹配时标记“字幕消歧”，避免同音字误报；
- 先识别作品信息、人物设定与正文章节，排除“类型、原作、时长、场景”等非台词内容；
- 在审片前预览被纳入和排除的剧本行、行号及判断理由；
- 将 ASR 与“角色：台词”格式的剧本做全局字符对齐；
- 报告疑似漏词、改词、加词，并保留剧本行和音频时间码；
- 提示低音量、疑似削波和高静音比例；
- 上传或粘贴 `.txt`、`.md`、`.fountain` 剧本文本；
- 检查人物知情边界、动作能力、外观、情绪和道具连续性；
- 将编导反馈拆为候选规则，人工确认后按项目跨版本复用；
- 下载结构化 JSON 音频审片报告；
- 提供固定离线评测和匿名用户验证记录页。

## 准确的产品边界

- 当前能分析视频音轨与画面硬字幕；
- 仅凭音频不能可靠确认说话人身份；
- OCR 只读取文字，当前仍不能根据画面判断动作、表情、服装、伤口和道具；
- ASR 可能受口音、音乐、噪声和多人重叠说话影响，所有异常均需编导回看确认；
- 固定样例只用于工程回归，不代表真实短剧行业准确率。

后续说话人、字幕和视觉审片规划见 [MULTIMODAL_ROADMAP.md](MULTIMODAL_ROADMAP.md)。

## 本地运行

需要 Python 3.11 或更高版本。

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器访问 `http://localhost:8501`。第一次运行音频审片时会从 Hugging Face 下载 Whisper 模型：`tiny` 更快，`base` 中文更稳但更慢。

## 推荐体验路径

1. 使用自动生成的匿名项目代码；
2. 在“视频音频审片”粘贴带“角色：台词”的已脱敏剧本；
3. 展开台词预检，确认作品信息和背景说明已被排除；
4. 上传一个已获授权的短剧单集或片段；
5. 先选择 `tiny`，点击“提取音轨并对照剧本审核”；
6. 查看时间码、疑似漏词/改词/加词和完整 ASR；
7. 回看视频确认异常，不要直接把 ASR 结果当成事实；
8. 提交一条明确的编导纠正，确认候选规则；
9. 保持项目代码不变，在后续版本验证记忆复用。

## 部署到 Streamlit Community Cloud

1. 在 Streamlit Community Cloud 创建应用；
2. Repository 选择 `moyue662-cloud/scriptlint-feedback-agent-demo`；
3. Branch 选择 `main`；
4. Main file path 填写 `app.py`；
5. 部署完成后分享生成的 `streamlit.app` 地址。

首次音频审片会下载模型，因此可能比后续运行慢。当前单文件限制为 200MB、音轨最长 12 分钟，建议演示时使用 1–3 分钟片段。

## 隐私与存储

- 仓库不包含 API Key、真实用户数据、本地数据库或开发者本机路径；
- 上传视频只写入运行实例的临时目录，处理结束后删除，不写入业务 SQLite；
- Streamlit 会在当前会话中暂存上传内容，公网 Demo 只应使用已脱敏、已获授权素材；
- 剧本文本、反馈规则和验证记录保存在部署实例的 SQLite；实例重启后可能丢失；
- 当前没有账户系统，项目代码是隔离键但不是安全的访问凭证；
- 不要上传未公开商业剧本、姓名、联系方式、合同或含未授权人员的视频。

更多说明见 [SECURITY.md](SECURITY.md) 和 [USER_VALIDATION_PROTOCOL.md](USER_VALIDATION_PROTOCOL.md)。

## 测试

```powershell
python -m pytest -q
```

测试覆盖反馈记忆、项目隔离、文本审计、剧本结构预检、剧本—ASR 对齐和 MP4/AAC → WAV 实际媒体解码。Whisper 模型首次下载与行业素材准确率需要单独做集成评测。
